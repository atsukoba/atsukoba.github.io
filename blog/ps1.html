備忘録

2.5. Bash Prompt Escape Sequencesによると，以下の通り。

  • \h => ホスト名
  • \u => ユーザ名
  • \w => ディレクトリ（フルパス）
  • \W => ディレクトリ
  • \t => 時間 (24 形式)
  • \T => 時間 (12 形式)
  • \@ => AM / PM
  • \d => 日付
  • \D => 日時
  • \# => コマンド番号
  • \! => ヒストリ番号
  • \n => 改行

表示としては，

1[<コマンド番号>(<ヒストリ番号>)] <時間 HH:MM:SS> <user> at <directory> [<branch>]

となる。

<branch>の部分では，parse_guit_branchを呼んでいて，その内部がではgit branch --no-colorの結果をsedで置換，エラー(2)を/dev/nullへ捨てている。

また，上記記事にもあるが，色設定として以下の変数化も使える

1local  BLUE="\[\e[1;34m\]"
2local  RED="\[\e[1;31m\]"
3local  GREEN="\[\e[1;32m\]"
4local  WHITE="\[\e[00m\]"
5local  GRAY="\[\e[1;37m\]"

ちなみに

PS2(The secondary prompt string)も設定できるみたいだが面倒なので放置。
